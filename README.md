# Login Page

A modern, responsive login page built with HTML, CSS, and vanilla JavaScript.

## ✨ Features

- Clean and modern UI design
- Fully responsive layout
- RTL support for Persian
- Light and Dark mode
- Email and password validation
- Password visibility toggle
- Remember Me checkbox
- Loading animation
- Toast notifications
- Google login UI
- OTP login UI
- Accessibility support

## 🎨 Color Palette

- Background: `#F7F9FC`
- Primary: `#2563EB`
- Accent: `#14B8A6`
- Card: `#FFFFFF`

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts (Vazirmatn & Inter)

## 📁 Project Structure

```text
login-page/
├── index.html
├── style.css
├── script.js
```

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Run `index.html` in your browser.

No additional dependencies or installations are required.

## 📝 Note

This project is a frontend login interface. Backend authentication and actual Google/OTP login integration are not implemented yet.
